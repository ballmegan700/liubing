# Fashion Design Portfolio

复古简约风格的个人服装设计作品集网站，使用静态 HTML、CSS 与少量原生 JavaScript，无需构建步骤。

## Sections
- Selected Work — 《茸朔·霜境》五套服装效果图
- Garment Development — 服装制作参考流程与院校资料
- Pattern Studies — 鹿茸、雾凇、枯枝、人参形态与纹样转化
- Inspiration & Research — 长白山/白头山冬季地貌与自然材料参考
- About / Contact — 个人介绍与联系方式

## Images
- 项目服装效果图与流程参考图存放在 `assets/`，使用相对路径引用，适配 GitHub Pages 的 `/liubing/` 项目路径。
- 自然参考照片来自 Wikimedia Commons，网页中保留了作者署名、源文件页与许可链接。若替换图片，请同步更新图注和授权说明。
- 所有图片支持点击放大；本地或远端图片无法加载时会显示备用提示。

## Deployment
GitHub Pages uses the included Actions workflow in `.github/workflows/pages.yml`.
